# Intelligent RPA Integration

## Overview
This skill executes controllable robotic process automation workflows across enterprise software, databases, and internal web portals.

## Capabilities
- Automates desktop application forms and enterprise browser workflows.
- Coordinates headless bot tasks and monitors execution status.
- Enforces strict human-in-the-loop checkpoints before executing sensitive corporate writes.
