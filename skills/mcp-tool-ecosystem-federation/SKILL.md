# MCP Tool Ecosystem Federation

## Overview
This skill manages dynamic integration of external MCP servers and internal iFLYTEK ecosystem tools into the agent runtime.

## Capabilities
- Ingests and registers external MCP tools conforming to JSON-RPC 2.0 schemas.
- Translates workflow inputs into tool invocation arguments with schema validation.
- Monitors tool availability, latency metrics, and error rates across providers.
